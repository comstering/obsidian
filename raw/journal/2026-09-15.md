## DBRE MySQL terraform 정리
1. Cluster, instance는 생성 후 state에서 제거, 이후 관리는 콘솔로 진행
   (master 계정을 위한 secrets manager도 생성)
2. Parameter group은 terraform으로 관리
3. github repo에 대한 CI 및 프로세스 관리는 DBRE에서 진행
### Security Group 정리
1. DBRE에서 사용하는 기본 공통 SG를 생성
2. 1번으로 먼저 DB 생성
3. DB 생성 이후 global-devops에게 해당 DB가 사용할 SG 요청
4. global-devops에서 SG 생성 후 DBRE에서 전달하여 SG 추가
5. 이후 SG 관리는 global-devops에서 inbound/outbound rule 관리
